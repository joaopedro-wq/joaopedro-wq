Sou Desenvolvedor Full Stack com mais de 3 anos de experiência na construção de produtos web. Trabalho entre produto, UX/UI e engenharia: entendo o problema, organizo os fluxos, construo a interface, desenvolvo APIs e acompanho a entrega.
