## Sobre mim

Sou Desenvolvedor Full Stack com mais de 3 anos de experiência no desenvolvimento de produtos web.

Atuo principalmente com Angular, TypeScript, PHP e Laravel, participando do processo completo: entendimento do problema, definição dos fluxos, construção da interface, desenvolvimento da API, integrações, testes e entrega.

Tenho interesse especial por produtos que combinam boa experiência de usuário com engenharia bem estruturada, código sustentável e decisões técnicas que facilitam a evolução do sistema.
